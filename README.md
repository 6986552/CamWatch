# CamWatch · 小巧摄像头预览

Windows 摄像头实时预览小工具。**无边框纯画面窗口**，所有功能都在右键菜单里，适合放在角落当悬浮监控。无第三方依赖，单个 exe。

## 使用

双击 `CamWatch.exe`。需要 Windows 10 及以上和 .NET 8 Desktop Runtime（本机已装则无需任何东西）。

### 右键菜单

| 功能 | 说明 |
|---|---|
| 摄像头 | 子菜单切换摄像头 |
| 截图 | `Ctrl+S`，保存到 `图片\CamWatch\` |
| 窗口置顶 | `Ctrl+T` |
| 画面镜像 | 水平翻转 |
| 移动红框 | 开关：移动物体区域标注红框 |
| 透明度 | 子菜单里的滑块（30%–100%），或 `Ctrl+↑/↓` |
| 全屏 | `F11`，`Esc` 退出 |
| 隐藏窗口 | 老板键 `右Ctrl + 右Alt + /?`，再按一次恢复 |
| 退出 | 关闭程序 |

**老板键**：按下 `右Ctrl + 右Alt + /?`（三个键都在键盘右下角，单手可按）立即隐藏整个窗口，再按一次恢复原位。任何位置都生效，不抢其他程序的普通 `Ctrl+Alt` 组合。

### 窗口操作（无边框）

| 操作 | 效果 |
|---|---|
| 左键拖画面 | 移动窗口 |
| 右键拖画面 | 等比调大小 |
| 滚轮 | 以鼠标位置为锚点等比缩放 |
| 双击画面 | 全屏 / 退出全屏 |

窗口宽高比自动跟随画面分辨率，**永远不会出现黑边**。窗口位置、大小、透明度等自动记忆（`%APPDATA%\CamWatch\settings.json`）。

### 移动标注

画面上出现移动物体时，会自动在移动区域画**小红框**标注（逐帧实时，不响铃不报警）。同一移动物（如走动的人）会合并为一个框，不再碎成很多小框；可在右键菜单「移动红框」中关闭。

> 虚拟摄像头（手机投屏类）需手机端先连接才有画面；启动时自动跳到第一个能出画面的摄像头。

## 重新编译（可选）

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -o out
# 发布出来的 out\CamWatch.exe 即为成品

# 发给没装 .NET 8 的电脑：
dotnet publish -c Release -r win-x64 --self-contained true -o out-standalone
```

源码：`CameraCapture.cs` 取流/位图转换/移动标注，`MainForm.cs` 无边框窗口与交互，`Program.cs` 入口（`--smoke-test` 自动化验证）。
